# Contributing to FrigateSpotter

Thank you for considering a contribution.

## Ways to contribute

- Report reproducible bugs.
- Suggest focused features and integrations.
- Improve documentation and examples.
- Submit fixes, tests, and implementation work.

## Before opening an issue

1. Search existing issues first.
2. Include your Frigate and Home Assistant versions when relevant.
3. Include camera/PTZ vendor and model only when it matters to the issue.
4. Remove passwords, tokens, private URLs, IP addresses, and other secrets from logs and configuration examples.
5. Provide the smallest configuration or reproduction that demonstrates the problem.

## Pull requests

- Keep changes focused and reasonably small.
- Explain the problem being solved and the approach taken.
- Add or update tests when behavior changes.
- Update documentation when configuration or user-visible behavior changes.
- Avoid unrelated formatting or refactoring in the same pull request.
- Ensure new dependencies have licenses compatible with Apache-2.0 distribution.

## Commit and code quality

Use clear commit messages and prefer readable, maintainable code over clever shortcuts. Automated formatting, linting, and tests should pass before a change is merged once those checks are available in the project.

## Licensing of contributions

Unless you explicitly state otherwise, any contribution intentionally submitted for inclusion in FrigateSpotter is provided under the Apache License, Version 2.0, consistent with Section 5 of that license.

By contributing, you represent that you have the right to submit the contribution under those terms.

## Conduct

Participation in this project is governed by [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Security issues

Do not open public issues for vulnerabilities that could put deployments, credentials, camera feeds, or networks at risk. Follow [SECURITY.md](SECURITY.md) instead.
